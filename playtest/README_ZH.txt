VX: AETHER KEEP - 试玩包 0.1.0

1. 解压到任意可写目录。
2. 双击 vx.exe，无需安装；Windows 10/11 x64。
3. 可用固定种子：vx.exe --seed 12345
4. 默认中文；English beta：vx.exe --lang en 或 F2 -> L。

操作
- 移动：WASD / 方向键 / 手柄十字键
- 天赋：1/2/3 或 LB/RB；确认：空格 / A；取消：Esc / B
- 炸弹：B（每局 1 个，商店可补）
- 背包：X / I；喝药：A / P
- 角色：Y / C；加点：方向键 + A
- 暂停：Start / Esc；帮助：H 或暂停页 Y
- 设置：F2；全屏：F11
- 每日挑战：F6 或职业菜单 Y
- 反馈：F3 复制诊断并打开试玩表单
- 仅复制诊断：F4

目标：到第 3 层击败深渊守卫。死亡即结束；R / Start 重开。

存档：%APPDATA%\lagudomeze\vx\saves（便携：vx.exe --portable）。
Demo 存档独立在 %APPDATA%\lagudomeze\vx\demo。
不会上传遥测。
