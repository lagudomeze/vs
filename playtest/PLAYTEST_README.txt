VX: AETHER KEEP - PLAYTEST BUILD 0.1.0

1. Unzip this folder anywhere writable.
2. Run vx.exe (no installer). Windows 10/11 x64.
3. Optional fixed seed: vx.exe --seed 12345
4. Language: default Chinese. English beta: vx.exe --lang en or F2 -> L.

CONTROLS
- Move: WASD / arrows / D-pad
- Talents: 1/2/3 or LB/RB; confirm: Space / A; cancel: Esc / B
- Bomb: B (one-use area attack; shops refill)
- Inventory: X / I; drink potion: A / P
- Character: Y / C; allocate points: D-pad + A
- Pause: Start / Esc; help: H or pause -> Y
- Settings: F2; fullscreen: F11
- Daily challenge: F6 or Y on the class menu
- Feedback: F3 copies diagnostics and opens the playtest form
- Diagnostics only: F4

GOAL
Reach floor 3 and defeat the Abyss Warden. Death is permanent; R or Start restarts.

SAVES
%APPDATA%\lagudomeze\vx\saves (portable: vx.exe --portable).
Demo saves are isolated in %APPDATA%\lagudomeze\vx\demo.
No telemetry is uploaded.
