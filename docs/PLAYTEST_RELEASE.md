# VX: AETHER KEEP - v0.1.0 playtest (early build)

Windows 10/11 x64. Not a Steam release. No AppID, no installer, no telemetry.

## Try it

1. Download vx-playtest-0.1.0.zip and unzip.
2. Run the exe (or the included launcher).
3. Read README_ZH / README and CONSENT first.

## What is in this build

- 3 classes, 3 floors, Abyss Warden boss
- 18 items, 7 elite affixes, 6 floor modifiers
- daily challenge + streak + 6 badges
- keyboard/gamepad, mouse panels, first-run hint
- save v3 with backups/autosaves; demo has separate saves

## Known limits

- English is beta; some text falls back to Chinese.
- No official Steam Input mapping, cloud conflict UI, achievements or overlay.
- Steam Deck/Proton not hardware-verified.
- Art/audio are prototype-level; trailer/capture are auto-bot, not human gameplay.
- This is not a release date/price commitment.
