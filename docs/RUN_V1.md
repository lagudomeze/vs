# RUN v1 — reference roguelike 风格 3D 像素 Roguelike 设计基线

> 目标调整：**玩法尽量接近 reference roguelike**（回合制、格子、职业/天赋、装备、掉落、楼层、Boss、死亡重开），**画面保留我们已有的 3D 模型 + 像素画风 + 固定俯视可旋转相机**。
> 这份文档取代 TACTICAL_V1 的时间冻结/实时前摇方向；TACTICAL_V1 只保留作为参考。

## 1. 一句话

选一个职业，在 3 层 13×13 的 3D 像素地牢里一格一格推进；每次行动后敌人行动；用天赋、装备和等级击败楼层 Boss；死亡即重开。

## 2. 设计支柱

1. **回合制**：玩家行动一次，敌人行动一次；没有实时自动攻击。
2. **格子**：移动、攻击、技能都基于 13×13 网格；3D 模型站在格心，视觉可插值，逻辑离散。
3. **职业/天赋**：三个 reference roguelike 风格职业，各自 3 个主动天赋 + 资源 + 冷却。
4. **装备/掉落**：装备改变属性；楼层有宝箱/掉落；背包可查/可换。
5. **可读性**：敌人意图、命中/伤害/冷却/状态都能从 HUD 和日志读到。

## 3. 核心循环

1. 开局菜单选择职业（1/2/3；`--hero` 直接开局并跳过菜单，headless 默认跳过）。选择后按当前 seed 刷新地牢，菜单显示的 SEED 即本局 seed。
2. 进入第 1 层：房间 + 墙 + 障碍 + 怪物 + 宝箱 +  stairs。
3. 玩家回合：移动/普攻/天赋/使用物品/等待。
4. 玩家行动后，所有敌人依次行动（移动/攻击/远程）。
5. 清层后走 stairs 进入下一层；第 3 层 Boss。
6. 死亡 → 结算/重开（R）。

## 4. 回合与行动经济

v1 用“回合 + 速度”的简化能量模型，不逐帧实时：

- 每个 actor 有 speed（100 基准）。
- 每回合 player 先行动一次；敌人按 speed 排序行动。
- speed ≥ 150 的敌人每 2 回合额外行动一次；speed ≤ 75 的每 2 回合少行动一次。
- 玩家一次行动 = 移动 1 格 / 普攻 / 天赋 / 使用物品 / 等待。
- 冷却、状态、资源回复按“回合”结算，不按秒。
- 玩家行动后立刻结算敌人回合；动画只是表现，不改变判定。

## 5. 网格与关卡

- 13×13 格，格心世界坐标；四周墙；内部随机房间/柱子/碎石/水/火盆（可阻挡或装饰）。
- 每层：入口、 stairs、2–4 个宝箱/掉落点、4–8 个敌人；第 3 层 Boss。
- 玩家/敌人占 1 格；不可重叠；不可穿墙。
- 移动 4 方向（WASD）；撞敌人 = 普攻；撞墙 = 不消耗回合。
- 相机固定俯仰，可 Q/E 或右键拖拽旋转；旋转不消耗回合。
- 视觉：逻辑位置离散；Transform 用 0.12s 插值到格心；转身朝向。

## 6. 职业与天赋（v1）

六属性：力量、敏捷、体质、感知、魔力、意志。

| 职业 | 资源 | 天赋 1 | 天赋 2 | 天赋 3 |
| --- | --- | --- | --- | --- |
| 狂战士 | 精力 | 重击：近战 2.0×，cd 4 | 冲锋：直线 2 格并击退，cd 6 | 战吼：3 回合 +30% 攻击，cd 8 |
| 元素法师 | 法力 | 火球：范围 1.5，2.5×，cd 5 | 冰锥：锥形 3 格，减速，cd 6 | 闪现：传送到 5 格内空地，cd 10 |
| 时空法师 | 悖论 | 时光箭：2.0× + 减速，cd 4 | 时间停滞：目标跳过 1 回合，cd 8 | 回溯：回到 2 回合前位置/血量？v1 只做位置，cd 12 |

- 天赋键 1/2/3；AP/资源不足或冷却中不可用。
- 普攻：撞敌人或按空格对相邻目标；伤害 = 攻击 - 护甲减免。
- 技能范围/目标：鼠标/方向键选格，Tab 切换目标；v1 先做“最近敌人/朝向格”。

## 7. 敌人与 AI

| 敌人 | 层 | 行为 |
| --- | --- | --- |
| 骷髅兵 | 1–3 | 近战追击 |
| 幽魂 | 1–3 | 远程 3–4 格，保持距离 |
| 石魔像 | 2–3 | 高血高甲，慢速 |
| 精英骷髅/幽魂 | 2–3 | 更高属性，掉好装备 |
| 深渊守卫 | 3 | Boss，近战 AOE + 召唤？v1 只做 AOE |

- AI：若相邻则攻击；远程保持距离；否则向玩家移动（A* 或贪心 + 阻挡检测）；不会自动寻路绕远（reference roguelike 风格可用 A*，v1 做简单 A*）。
- 敌人意图：目标格高亮/箭头；攻击前显示预计伤害（v1 可选）。

## 8. 属性、装备、掉落

- 六属性决定 HP/资源/攻击/护甲/暴击/速度。
- 装备槽 v1：主手、身体、饰品；品质普通/稀有/史诗；固定词条。
- 宝箱/敌人掉落；I 打开背包，数字键装备；C 打开角色面板。
- XP：击杀/清层；升级 +1 属性点（v1 自动加主属性）并回满资源。
- 3 层通关；Boss 掉史诗；死亡重开。

## 9. UI

- 左上：职业/等级/HP/资源/回合数。
- 底部：天赋栏 1/2/3 + 消耗/基础冷却/当前状态；底部一行天赋效果说明；空格普攻；I 背包；C 角色（含天赋说明）。
- 开局：三张职业卡显示资源、生命、定位、3 个天赋名与一行效果；1/2/3 选择并开始。
- 右上：本层信息（层数、剩余敌人、stairs 方向）。
- 顶部中央：回合提示/危险提示。
- 左下：战斗日志（最近 5 条）。
- 敌人：目标格高亮 + 血条；当前目标显示名字/等级。
- 中文像素字体沿用 Ark Pixel 子集。

## 10. 技术结构

- 保留：renderer、model/rig、arena_mesh 可改造成 dungeon tiles、相机、字体、资产管线。
- 新增/重写：
  - src/game/turn.zig：回合队列、玩家行动、敌人回合、速度。
  - src/game/grid.zig / dungeon.zig：网格、关卡生成、A*、LOS。
  - src/game/attributes.zig / items.zig / content.zig：B 负责。
  - src/game/game.zig：单角色、楼层、输入、回合驱动、渲染。
  - src/game/hud.zig：hotbar/角色/背包/日志。
- 现有实时 systems（Formation/Movement/EnemyAI/HeroCombat）不再用于战斗；保留动画/粒子/光照。
- 单角色：开局选职业；其余两个职业作为可选角色，不再同屏三人。
