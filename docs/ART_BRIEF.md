# VX: AETHER KEEP — 美术外包需求单

状态：需求单，不是已签约/已交付。当前商店素材为程序化占位，见 [store/README.md](store/README.md)。

## 1. 项目一句话

单英雄、回合制、网格地牢 Roguelike；3D 低多边形场景 + 像素角色/UI；三职业、三层、精英词缀、永久死亡。

## 2. 视觉支柱

- 暗色地牢，青蓝环境光 + 金色交互/奖励
- 低多边形几何场景，像素角色与图标保持锐利
- 64 色限制感；不要写实 PBR、不要光滑 3D 渲染
- 可读性优先：敌人意图、危险格、楼梯/商店/祭坛必须一眼分辨

## 4. 规格

- sRGB；PNG 无损或 JPG 90%
- 胶囊不要放小字；平台会缩放
- 截图不含调试 HUD、控制台、鼠标
- 预告片无版权音乐；字幕中英
- 交付源文件分层，字体授权可商用
- 不使用未授权的参考图/素材
