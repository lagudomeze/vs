## About This Demo（EN）

VX: Aether Keep is a turn-based grid roguelike with a low-poly 3D dungeon and pixel-art HUD. This demo contains:

- Floor 1 only
- Warrior class only
- Turn-based movement, talents, potions, bombs
- Shrines, shops, chests, elites
- Permanent death and restart

The demo ends when you reach the stairs. Your demo save is separate from the full game.

- 永久死亡与重开
- 踩楼梯结束，Demo 存档独立
