# 发行节奏与定价（计划稿）

状态：计划稿；没有确定发行日期，也没有创建 Steam 页面。日期一律用相对周（W-8…W0），避免虚构。

## 1. 定位

- 单英雄、回合制、网格 Roguelike
- 3 职业、3 层、永久死亡、可见敌人意图
- 像素 + 低多边形，短局 20–40 分钟
- 价格带：独立小品，不做 3A 定价

## 2. 定价

| 项目 | 建议 |
| --- | --- |
| 基础价 | $9.99 / ¥42 |
| 首发折扣 | 10%，2 周 |
| 永久降价 | 不发售即永久降价 |
| Demo | 免费，独立 App |
| 原声/艺术包 | 暂不做 |

原则：

- 不靠“临时工价”误导
- 不在 Next Fest 期间额外叠加大折扣
- 区域定价用 Steam 推荐曲线，再人工检查低价区
- 先跑 Playtest，再定最终价

## 3. Demo 范围（建议，未实现）

目标：让玩家在 20 分钟内理解循环，但保留完整版内容。

建议：

- 只开放第 1 层 + 一个职业（或三职业但 1 层）
- 保留商店/祭坛/精英/炸弹
- 到达第 1 层楼梯后显示“DEMO END + Wishlist”
- 不含第 2/3 层、Boss、3×3
- 存档独立，不继承到正式版（或明确说明）

已实现：--demo 只开放第 1 层，踩未封印楼梯显示 DEMO END + WISHLIST；存档隔离到 vx/demo；tools/demo_pack.ps1 生成 zip。未限制职业/3×3，未创建独立 Steam Demo App/Depot。详见 [DEMO.md](DEMO.md)。

## 5. 愿望单与反馈指标

- 商店页转化：访问 → 愿望单
- Demo 试玩 → 愿望单
- Next Fest 期间每日愿望单
- 首周退款率/差评原因
- 不买评论、不刷愿望单

## 6. Press/内容

- Press kit：logo、key art、截图、预告片、事实表
-  contacting：小站点/主播，先问规范
- 不群发同一模板给无关的人
- 不用“GOTY”“最好玩”这类无法证明的文案

## 7. 风险

| 风险 | 应对 |
