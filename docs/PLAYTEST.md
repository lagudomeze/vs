# Playtest 流程与反馈模板

目标：在 Steam 页面/Next Fest 前，用 5–10 名玩家验证前 30 分钟的留存、理解与难度。

## 1. 构建

~~~powershell
zig build -Doptimize=ReleaseFast
powershell -ExecutionPolicy Bypass -File tools/package.ps1
~~~

产物：dist/vx-<version>-win64.zip；分发包用 tools/playtest_pack.ps1 生成，见 [PLAYTEST_KIT.md](PLAYTEST_KIT.md)。
测试者解压即玩，不需要安装；存档在 %APPDATA%\lagudomeze\vx。

## 2. 30 分钟脚本

1. 不解释，直接让玩家从职业选择开始。
2. 观察前 5 分钟：是否知道 WASD/方向键移动、1/2/3 瞄准、空格确认。
3. 让玩家打到第 2 层；中途不提示，除非卡住超过 60 秒。
4. 询问一次：“你现在最想做什么？为什么？”
5. 结束前让玩家选择：继续、重开或退出；记录原因。

## 3. 记录表

| 字段 | 说明 |
| --- | --- |
| 测试者 | 昵称/编号 |
| 版本/种子 | 例如 v0.x seed 12345 |
| 职业 | 狂战士/元素法师/时空法师 |
| 到达层数 | 1/2/3 |
| 死亡原因 | 普通怪/精英/Boss/陷阱/其他 |
| 卡住点 | 具体房间/面板/操作 |
| 最困惑的 1 件事 | 原话 |
| 最满意的 1 件事 | 原话 |
| 是否愿意再开一局 | 是/否/不确定 |
| 是否愿意加愿望单 | 是/否 |

## 4. 访谈问题

- 你如何描述这个游戏的一句话？
- 哪个词缀/敌人最需要你想对策？
- 哪次死亡让你觉得“是我的错”，哪次觉得“不公平”？
- 背包/角色面板是否看得懂？有没有找不到的功能？
- 声音/音乐是否干扰或帮助？
- 你会把它推荐给谁？

## 5. 成功指标（首轮）

- 80% 测试者能在 2 分钟内完成第一次移动与攻击。
- 60% 能到达第 2 层。
- 50% 愿意再开一局。
- 严重 UX 阻塞（不知道如何确认/退出/使用药水）≤1 人。
- 不出现崩溃/存档损坏。

## 6. 反馈归档

- GitHub issue 标签：feedback / playtest / balance / bug / ux

- 结构化表单：[playtest_session.yml](../.github/ISSUE_TEMPLATE/playtest_session.yml)
- 游戏内 F3：复制诊断并打开该表单
- 标题格式：[Feedback] 一句话结论
- 必填：版本、种子、职业、复现步骤、期望/实际；游戏内按 F4 复制诊断后粘贴
- 平衡问题附 QA 数据或种子；不要只写“太难”。

## 7. 禁止

- 不收集个人信息。
- 不默认上传遥测；如需日志，让测试者手动附上。
- 不在公开商店页承诺未实现功能（联机、云存档 API、成就等）。
