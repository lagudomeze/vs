## Short description

A pixel-art dungeon crawl where one hero, three classes and a deterministic seed decide whether you reach the Abyss Warden.

## Long description

VX: AETHER KEEP is a turn-based grid roguelike rendered in a 640x360 software rasterizer and presented at 3x nearest-neighbor scale. Pick a Warrior, Mage or Chronomancer, descend three floors, and spend talent points, loot and shrine boons before the floor boss seals the stairs.

Every run is deterministic from its seed: share a seed, compare routes, or play the UTC daily challenge. Elite affixes, floor modifiers and cursed chests change the answer each floor. Death is permanent; records persist.

## Features

- Three classes with distinct resources and talent kits
- Turn-based grid combat with telegraphed intents
- Deterministic seeds, daily challenge, local badges
- Loot, shops, shrines, elite affixes, floor modifiers
- Pixel-art HUD, procedural low-poly 3D scene
- Chinese + English beta UI, keyboard/gamepad support
- No telemetry; saves are local and Auto-Cloud friendly
